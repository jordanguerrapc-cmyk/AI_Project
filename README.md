 Proyecto de IA - Sistema de Recomendación

## Objetivo
Crear un sistema de recomendación simple en Python que sugiera productos relacionados según sus categorías.

## Herramientas utilizadas
- Python
- Visual Studio Code
- Git y GitHub
- GitHub Copilot

## Funcionamiento
El programa muestra una lista de productos. El usuario escribe un producto, por ejemplo `Laptop`, y el sistema recomienda productos que comparten categorías como tecnología, estudio o trabajo.

## Prueba realizada
Al escribir `Laptop`, el programa recomendó:
- Tablet
- Smartphone
- Audífonos
- Teclado
- Libro de Python

## Proceso seguido
1. Creación del repositorio en GitHub.
2. Creación del archivo `.gitignore` para Python.
3. Clonación del repositorio localmente.
4. Creación de `recommendation_system.py`.
5. Ejecución y prueba del sistema en Visual Studio Code.
6. Commit y Push de los cambios a GitHub.
